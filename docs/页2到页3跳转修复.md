# 页2进入页3跳转修复

## 问题与设计原因
页2与页3共用主图容器 `#scImages`。旧代码把该容器当作页3独有标志，在页2尚未点击进入按钮时就判定跳转成功，跳过了实际点击。

## 修改及优点
`chrome_extension/content/page2.js` 用 `isPage3Destination` 核对目标主机和发布页路径。点击前与点击后的轮询采用同一判定；保留两次点击、重新定位按钮和失败上报。共享图片区域、参数变化以及登录页面不再当作成功。

## 能力边界
此修复负责页2到页3的目的地址判定，不改变上传、类目选择、任务参数透传和页3保存逻辑。不会替用户保存或上架。完整上传、选择类目、点击后进入页3的真实端到端路径仍待加载新版验证。

## 验证
真实页2 `/product/easyListing.htm` 存在 `#scImages`，旧判定为真，新判定为假，复现并确认误判。
`tests/test-page2-navigation.js` 运行真实源码的跳转分支，覆盖共享容器仍执行首次点击、到达目标页成功、无跳转两次重试失败、登录页不能冒充成功。专项、语法及差异检查通过。
开发工作区全量97文件82通过、12个既有失败、3个既有超时，没有新增失败；不能称全量通过。
