# 尺码模板确认及实际测量值核验

## 原因
第60批row13一键填入后，保存前检查发现尺码表缺少测量数字。原fillSizeTemplate尝试处理“清除尺码表数据”确认后调用通用waitDialogsGone；弹层未关时该函数会按ESC，模板应用可能被取消，但found标记只表示点击过模板选项，仍打印“已选择模板”。日志和现场均显示测量值未落入。

## 修改与优点
复用原fillSizeTemplate和原类目选项，不另建上传流程。page3-review-size.js新增confirmTemplate和waitMeasurements，原函数委托这两个小模块处理结束条件：限定已知、唯一的尺码确认弹窗；只点击一次原生确认按钮，避免调试连接导致坐标偏差；检查身份、补缺全空条件、按钮可用及命中，等待慢出现/动画遮挡，取消ESC收尾。确认未结束则报未完成，不猜测成功。

恢复尺码只看实际input.checked，并排除表头/浮层，不重复切换已有选择。等待每个必填测量输入实际为数字后才记录模板成功；保留补缺全空前提和原尺码选择一致性保护。普通一键填入也不再把仅选中模板当作实际填写成功。

## 边界
只修全空测量区；已有任何测量值不重选模板，不覆盖用户自定义数据。未知弹窗、遮挡持续不消失、身份变化、模板本身无完整数字均停止。确认和测量等待分别最多约6秒，不无限重试，不自动解除整批暂停。检查不能判断数字语义是否适合该款服装。

## 测试与真实证据
test-size-template-confirm.js调用真实fillSizeTemplate和新确认模块，覆盖原生确认只一次、弹窗不关闭不按ESC、无数字不报成功、未知/遮挡、已有值保护、尺码不重复切换、迟到弹窗、延迟数字和身份变化；既有size复用专项通过。
