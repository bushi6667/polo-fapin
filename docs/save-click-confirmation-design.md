# 保存点击确认与单次补救

## 原因
第60批第2行首次保存前检查通过，但14:59:15发出点击后，页面保存监听命中数0，14:59:18被判未确认并暂停。原realClickCDP只确认鼠标指令执行，没有确认实际按钮点击；底部固定保存按钮在调试连接/视口变化后可能偏移。历史资源缓冲区已满，不能用缺少网络条目断言没有保存请求；具体未命中原因仍未证实。

## 修改与优点
新增upload/save-click.js，区分鼠标发送与页面接收。保存操作先激活标签、建立独立点击观察；调试连接完成后重取唯一可用保存按钮坐标，命中测试排除遮挡。不改变其他填入步骤的鼠标逻辑。

鼠标完成后读取保存点击/按下事件：收到点击就只核验保存；明确无保存按下/点击且没有发送中断，才允许一次原按钮click补救。补救前再次核对同一页面、同一观察标记及按钮身份/遮挡；已有点击、部分鼠标动作、上下文丢失或页面切换均不重复。已开始鼠标操作但页面快速切换时仍进入结果核验，不因点击观察丢失直接认定失败。观察监听在结束时清理，拒绝并发保存。

保存反馈窗口2.5秒延长到8秒，保留20秒单次请求上限、平台明确报错优先和成功证据要求。新增任务日志saveClick和saveVerification，记录商品行、方法、是否接收、是否部分发送、失败原因及平台信号。不能只凭点击、按钮禁用或消失判保存成功。

## 能力边界
不按评分重填，不自动重发已经触发但未确认的保存。原按钮click补救依赖平台接受正常DOM点击；若平台拒绝或需人工交互，则仍会停止并给出证据。不能证明任意平台版本和网络条件均能保存；8秒后迟到结果仍可能需要人工确认。未改Excel、源产品或队列行，不恢复当前100件队列。当前页面尚未加载新增后台代码，需重载后实测；不将模拟通过当作真实保存通过。

## 测试
新增test-save-click.js运行真实模块和真实鼠标函数，覆盖连接后新坐标、点击确认、只补点一次、按下后中断不重放、页面切换、遮挡、禁用、并发、异常和监听清理。保存校验84项、回声51项及复查后台闸门/运行器专项通过。全量结果见本批时间记忆。

最终全量：112文件99通过、12既有失败、1既有超时；新增保存点击专项通过，旧文件状态无变化。当前真实页面仅执行新模块目标只读定位（中心1448,896）并清理，没有点击保存；新后台实际保存回归待重新加载。

## 2026-11-04 保存成功后空探针恢复
真实保存已收到mouse点击，平台重载到itemId=1602004547448，但executeScript成功resolve为空，没有抛异常。原代码只在catch里读取新地址，导致实际保存成功仍暂停。本次明确修复这一已实证分支。

新增upload/save-evidence.js：首次保存仅接受post.alibaba.com的保存成功页或数字itemId草稿目的页；登录、错误页和已有商品ID变化均不可放行。探针每轮把本次明确成功/失败信号写入sessionStorage，使用独立随机token、源地址、文档timeOrigin及时间隔离；重载后读取并清理。相同URL再次保存必须有本次明确成功且文档确已重载，不能凭旧保存记录或按钮变化放行。明确错误优先于成功；存储失败仍保守未确认。

该证据仅解决保存真实性识别，最终仍必须进入保存后全项检查、仅补空缺、再次保存复查、通过才完成当前队列行，不改变批量检查目标或字段补填语义。当前实际保存后的错误进度仍待新后台加载后单商品回归；不通过手动改verified来冒充成功。

补充实证：同URL第3/4/5次明确回归保存均收到mouse事件且平台新文档出现；MutationObserver捕获next-message-success next-toast next-overlay-inner“保存成功, 3秒后自动刷新”。sessionStorage里也有本次成功证据，说明并非平台不出提示。问题为重载交叠：空探针返回后读取可能仍命中旧文档，读后删除证据、立即以未重载拒绝，旧页面后续又写入同token证据。现在保存核验最多额外等3秒、每250ms读取新文档，并在后台保留已读的本次证据，等文档更替后确认，不重发保存。新增真实verifyPublishSaved集成反例：第一次读同旧doc、第二次新doc且存储已清，仍正确恢复；探针只调用一次。该等待不增加自动保存次数。

最终真机补充：第一次证据read因导航间隙失败时须继续等待，不能以captured=null提前退出。补充抛错/空frame反例后全量113文件100通过、12既有失败、1既有超时。使用磁盘同一源函数临时加载现场验证真实保存、自动复查和队列当前行入账成功（1已完成/99待处理，仍暂停），标题和FAQ与基线完全一致，诊断已清理。该临时函数已恢复，实际继续前须重载最终磁盘代码；未提交推送，跨商品连续运行仍待实测。
