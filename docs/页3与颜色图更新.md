# 页3与颜色图更新（扩展1.1.1）

## 设计原因与变化
颜色文字通过blur提交并回读，避免额外真实点击使平台清空文字；逐字输入失效时，使用原生赋值恢复并再次失焦确认。
颜色图与颜色名称分开检查。补图仅定位当前颜色行，已有图片保留，不按全局索引回退到其他行；取图等待期间重新检查当前商品、颜色名称和已有图片。后台校验Excel文件身份、行号、颜色及本地来源，身份不一致停止。
主图和细节图上传器新增独立追加动作，可识别已有文件名时只上传缺图，既有主动整组上传流程仍保持原模式。
页3增加“检查并修复（手动测试）”入口。检查空缺并回读结果，不自动保存、不上架、不推进队列。配套库存虚拟表、FAQ、颜色图模块一起加载。

## 优点
补缺流程不再为补一格而清空整组；读取期间页面或内容变化会再次校验；来源不明确、区域未加载时明确报告未解决。

## 能力边界
此版本仍是手动检查试验，不开启自动检测。尺码选择、尺码模板、箱规、公司模板和定制模板等暂不执行可能覆盖已有内容的自动重选。平台随机文件名的细节图不能可靠映射原素材，不猜填。自定义颜色缺本地明确来源时不补图。FAQ多条全空的最新来源集合匹配方案已做模拟回归，尚未做新版真实按钮回归；不能声称所有检测完美。

## 验证
已真实验证：删White单图、删Black/Navy双图后只补缺图，颜色名称与其他图源保留；完整页面重复检查快照不变；FAQ单条及双条删除一次补回，强制重渲染后内容保留；现有单条问答双空及跨条单字段缺失补回。
新增颜色文字专项运行实际源码片段，覆盖保留已有名称、避免清空式提交点击、逐字输入丢失后恢复。颜色图、FAQ、库存、追加上传及后台桥接专项已有测试。发布全量结果见时间记录，存在既有失败/超时，不宣称全量绿。

## 使用
更新文件后重新加载扩展，重新打开需要操作的页3。未保存商品页的刷新由用户自行决定；本次发布不会替用户保存或刷新商品。
