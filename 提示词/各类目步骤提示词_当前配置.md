## shirt

### 步骤 · 111 卖点图

|   |   |
| - | - |

- upload: original | imageSource: product
- 后处理: 111扩图.js、111卖点图后处理.js

```
[MODAL_INSTRUCTION]
步骤一：强制规则（不遵守就重来）
1、衣服颜色必须和图1一模一样。不准自己改颜色。
2、衣服款式必须和图1一模一样。衣服占画面15%大小，剩下85%全部留空.
3、只生成一张图。不准加任何多余的东西。
4、画面里不准出现人、模特、身体部位。只准出现衣服。
5、不准出现中文、英文、品牌名、水印、装饰、任何文字。
6、不准出现任何文字、标点、数字、符号。

步骤二：构图
2、背景：浅灰色
3、衣服平铺在画面正中间

步骤三：自检（生成之前必须检查，不合格就重来）
- 衣服颜色和图1一样吗？不一样 → 重来。
- 有任何文字吗？有 → 重来。
- 有任何装饰吗？有 → 重来。
生成。
```

### 步骤 · 444 白底图

|   |   |
| - | - |

- upload: original | imageSource: product
- 后处理: 444扩图.js、444叠加后处理.js

